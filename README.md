# 🚦 First Step Learning - Advance Traffic Light

Proyek pertama saya di GitHub untuk mempelajari **Git Version Control** sekaligus mengimplementasikan **Smart Pedestrian Traffic Light System** berbasis Arduino.

## 🛠️ Fitur & Spesifikasi System
- **Lalu Lintas Utama:** Kontrol otomatis 3 LED (Merah, Kuning, Hijau).
- **Lalu Lintas Pejalan Kaki:** Kontrol 2 LED (Merah, Hijau).
- **Push Button Request:** Fitur interaktif permintaan penyeberangan dengan jeda aman (*safety delay*) sebelum sinyal berubah ke merah.
- **Visual Warning:** Efek kedip (*blinking*) pada sinyal pejalan kaki saat waktu menyeberang akan habis.

## 🧰 Rangkaian & Pinout
- LED Utama: Merah (Pin 12), Kuning (Pin 11), Hijau (Pin 10)
- LED Pejalan Kaki: Merah (Pin 9), Hijau (Pin 8)
- Push Button: Pin 2 (INPUT_PULLUP)
